# optional-skills

不自动进入 Cursor 的 skill 目录，避免每轮对话灌 description。

需要时由用户点名，再读对应 `SKILL.md`。索引见 `../skills-reference.md`。

包括：审查 / TDD / 调试 / 合并冲突（`code-review` / `tdd` / `diagnosing-bugs` / `resolving-merge-conflicts`）、主流程（grill / to-spec / implement / wayfinder 等）、设计词汇（`codebase-design` / `domain-modeling`）、调研（`research` / `prototype`）。
